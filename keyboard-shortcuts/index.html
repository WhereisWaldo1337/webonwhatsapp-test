WhatsApp Web keyboard shortcuts

In a browser, WhatsApp Web shortcuts are Ctrl + Alt + a key on Windows and Cmd + Ctrl + a key on a Mac: N for a new chat, E for emoji, L to lock. Adding Shift usually acts on the open chat.

Three worth learning first

  • New chat, then start typing a name: faster than scrolling the chat list.
  • Mark as unread as a reminder to come back to a chat you cannot answer now.
  • Lock screen when you walk away from a computer other people can reach. It needs app lock to be set up first.

Answering customers all day? In the WhatsApp Business app, typing / in the message box inserts a saved quick reply, on WhatsApp Web too. See WhatsApp Business on the web.

Questions people ask

Where is the list of shortcuts inside WhatsApp Web?

Open Settings in WhatsApp Web and look for Keyboard shortcuts. That panel shows the list for the version you are running, which is the one to trust when it differs from any table on the web, including this one.

Why does WhatsApp Web use Ctrl + Alt instead of just Ctrl?

WhatsApp does not say, but the pattern is clear: the browser already owns the simple combinations. Ctrl + N opens a new browser window, so WhatsApp Web uses Ctrl + Alt + N on Windows and Cmd + Ctrl + N on a Mac.

Is there a shortcut for next and previous chat in WhatsApp Web?

WhatsApp's own table for the browser version does not list one. The desktop apps have it: Ctrl + ] and Ctrl + [ in the Windows app, Cmd + Shift + ] and Cmd + Shift + [ in the Mac app.

Can I change or add WhatsApp Web shortcuts?

Not in WhatsApp. The shortcuts are fixed. Browser extensions that add shortcuts need access to everything in your WhatsApp Web tab, which is a privacy risk we do not recommend.

Why does a shortcut not work for me?

Another program or a browser extension may have claimed the same combination, your keyboard layout may place the character elsewhere (the slash and comma shortcuts are the usual victims), or the focus is outside WhatsApp. Click inside the chat list and try again.
